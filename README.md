# RRFS app (Android)

This page is where the RRFS app for R R Filling Station staff is published.
It holds only the app file (APK) for each version and a small `latest.json` file that the app reads to know
about updates. The app's code is not here.

## Install the app (once per phone)

1. On the phone, open this page in the browser:
   https://github.com/AbhishekShukla-SF/rrfillingstation-apprelease/releases/latest
2. Tap the `.apk` file to download it, then open it. If the phone asks, allow the browser to install apps.
3. Open **RRFS** and log in with the same username and password you use on the website.

## Updates

You don't need to come back here. RRFS checks for a new version every time it opens and installs it with
one tap. The first time, Android asks you to allow RRFS to install updates. Tap **Allow**.
